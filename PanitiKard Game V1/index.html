    Owner/Editor Results · Stored Response Record

    Nasa ibaba ang buong tala ng bawat respondent: pangalan, paksa, score, mga sagot na kailangang balikan, at detalye ng performance. Hindi ipinapakita ang seksyong ito sa answering flow ng respondent.

    Pamamahala ng Episode

    Magdagdag ng episode at ilagay ang pamagat o detalye, plot twist o karagdagang nilalaman, at file attachment o reference. Ang seksyong ito ay para lamang sa editor.

    Database ng mga item

    Piliin ang Ayusin sa isang item o magdagdag ng bagong kard. Ang mga pagbabago rito ay para lamang sa kasalukuyang pagbubukas ng pahina.
