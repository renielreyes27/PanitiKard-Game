# PanitiKard

**An Interactive Filipino Literature Card Game**

PanitiKard is an educational card game designed to help students learn and understand Filipino literature through interactive questions, challenges, and activities.

The project aims to make learning Filipino literary concepts more engaging through a card-based gameplay experience.

## Project Versions

### PanitiKard V1
The original version developed using Canva AI. It serves as the initial implementation and reference for the system's features, content, and gameplay mechanics.

### PanitiKard V2
A redesigned and rebuilt version using HTML, CSS, and JavaScript. It aims to provide a standalone, responsive, and more flexible experience.

## Learning Topics

- **Pagsusuri ng Elemento ng Akda** – Understanding the elements of literary works.
- **Pagpapakahulugan sa Pahayag** – Understanding implications, meanings, and messages in literary statements.

## Card Types

The game includes seven types of cards:

1. Question Card
2. Statement Card
3. Correction Card
4. Bonus Card
5. Reverse Card
6. Help Card
7. Challenge Card

## Running PanitiKard V2

1. Clone or download this repository.
2. Open the `PanitiKard Game V2` folder.
3. Open `index.html` in your web browser.

No additional dependencies or build tools are currently required.
